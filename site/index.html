Five answers per app

What “present” means

Each answer is a version, and every version is checked against the dates in CREED's policy.json. State is never decided in code.

  1. PHP image

    The runtime the app really ships on, read from the app list's image tag.

  2. PHP floor

    The lowest PHP the app's composer.json allows. * counts as no floor at all.

  3. Laravel

    The installed version from composer.lock, never a guess.

  4. Auth package

    Which sign-in package is installed: SESAME, a CAS client, or none.

  5. PROCTOR

    pass, fail or none, read from PROCTOR's JSON report. ROLLCALL never re-runs a rule.

Each version lands in one of four states

  • active fully supported
  • security_only fixes only, a date is coming
  • eol past its security date, or older than anything the policy lists
  • unknown newer than the policy knows, or a tag nobody can parse

Real output

The register, in your terminal

This is ROLLCALL 0.1 run against its bundled fixtures: four demo apps, no network, no token. scan calls the roll and saves the day's snapshot; report reads it against the policy.

Every gap in a source becomes a note on that app, never a failed scan. A refused GitLab token stops the scan loudly instead of handing you a flattering partial answer.

exit 0 however the fleet looks. There is no exit 1: ROLLCALL takes attendance, it does not hand out detention.

Drift and the burn-down

Watch the back row empty

One snapshot per scan day. Count the apps on an EOL image each day and you get a line that should only go one way.

Drift, counted per kind

  • image_eol runs on an EOL PHP image
  • image_unknown an image tag nobody can read
  • image_below_floor the image is older than the app allows
  • floor_allows_eol composer.json still lets an EOL PHP in
  • floor_unbounded no PHP floor declared at all
  • eol_past_grace past the policy's grace days
  • laravel_eol Laravel past its security date
  • proctor_missing no PROCTOR report on file
  • proctor_failing PROCTOR says fail
  • override_expired a PROCTOR override ran out

rollcall drift also compares the policy with a saved endoflife.date page. A difference is a flag for a person; the policy stays the source of truth.

From a checkout, with the bundled fixtures

Quick start

No network, no token. Install dependencies once with composer install, then call the roll. PHP 8.3 or newer.

bash

export ROLLCALL_POLICY_FILE=tests/fixtures/policy.json
export ROLLCALL_REPOS_DIR=tests/fixtures/repos
export ROLLCALL_IMAGES_FILE=tests/fixtures/images.json
export ROLLCALL_PROCTOR_DIR=tests/fixtures/proctor
export ROLLCALL_STORE_DIR=var/snapshots
php bin/rollcall scan
php bin/rollcall report

PowerShell, no bash or WSL needed

$env:ROLLCALL_POLICY_FILE = "tests/fixtures/policy.json"
$env:ROLLCALL_REPOS_DIR = "tests/fixtures/repos"
$env:ROLLCALL_IMAGES_FILE = "tests/fixtures/images.json"
$env:ROLLCALL_PROCTOR_DIR = "tests/fixtures/proctor"
$env:ROLLCALL_STORE_DIR = "var/snapshots"
php bin/rollcall scan
php bin/rollcall report

rollcall scan

Calls the roll once and stores <date>.json. Scan twice in a day and that day's snapshot is replaced.

rollcall report

--format=text|json|prometheus. --internal adds the per-app list; keep that inside the project.

rollcall drift

--feed=<file>: a saved endoflife.date page. ROLLCALL never fetches it itself.

In Laravel

The package registers itself. Publish the config, then schedule the scan.

php artisan vendor:publish --tag=rollcall-config
php artisan rollcall:scan

Classroom rules

For noticing who is missing, not for shaming them

  • 1

    It enforces nothing

    No issues opened, no comments, no deploys. It exits 0 whatever it finds.

  • 2

    Counts, not names

    The public report is counts and progress only: no app names, no owners, no ranking.

  • 3

    Read-only everywhere

    GET and HEAD only, and a test fails if a write verb shows up. The one thing it writes is its own snapshot folder.

  • 4

    Metrics stay off

    Until you turn them on. Then /metrics wants a bearer token or an allowed address; with neither, nobody gets in.
